# ShutaNote

一款原生 Windows 自由白板笔记应用，基于 .NET 8 和 WPF。

## 功能

- 5000 × 3500 自由画布，支持平移与 25%—300% 缩放
- 网格线底板，鼠标附近显示低强度、边缘羽化的主题色圆形光晕
- 文字块、字体/字号、粗体、斜体、下划线和颜色
- 自由画笔、矩形、椭圆、菱形、箭头
- 导入图片和直接使用 `Ctrl+V` 粘贴剪贴板图片
- 元素框选、拖动、缩放、删除
- 多白板管理、自动本地保存、撤销与重做
- 按内容范围导出透明白板为 PNG（白色背景）
- 半透明毛玻璃前景 UI，可在设置中调整 35%—100% 不透明度
- GPU 画布：D3D11 BGRA 共享纹理、Direct2D 网格/笔迹/图形/图片、DirectWrite 文本、D3D9Ex `D3DImage` 承载
- GPU 设备移除后自动重建共享表面；重建失败自动回退到 WPF 软件画布
- 低延迟交互：绘画期间按合成帧批量采样，Direct2D 直接增量绘制活动笔迹
- GPU 仅创建视口大小共享表面，平移和缩放时按可见区域重绘；窗口移动期间暂停大型表面呈现
- 自动保存采用 180ms 防抖和串行后台写入，窗口关闭前会同步提交最后快照
- 浅色/深色模式与五套主题配色，外观设置自动保存
- 完全自绘无边框窗口、标题栏、窗口控制按钮、消息弹窗和文件浏览器，不显示 Windows 原生对话框
- `F11` 一键进入专注白板模式，仅保留画布和底部迷你工具条
- 支持将白板窗口置顶并贴靠桌面工作区顶部

## 快捷键

| 按键 | 功能 |
| --- | --- |
| `V` | 选择 |
| `H` | 平移 |
| `P` | 画笔 |
| `T` | 文字 |
| `R / O / D / A` | 矩形 / 椭圆 / 菱形 / 箭头 |
| `Ctrl+Z / Ctrl+Y` | 撤销 / 重做 |
| `Delete` | 删除所选 |
| `Ctrl+V` | 粘贴图片 |
| `F11` | 显示/隐藏界面，切换专注白板模式 |

数据默认保存在 `%LOCALAPPDATA%\ShutaNote`，不上传网络。

GPU 设置位于“设置”面板。默认尝试 GPU 画布；如果显卡驱动、远程桌面或系统组件不支持初始化，应用会自动切换到 WPF 软件画布。开启“显示 GPU 诊断信息”可查看当前后端、共享表面、笔迹和元素数量。文本编辑时会临时显示 WPF `TextBox`，失焦后恢复 DirectWrite 绘制。

### 故障排查

- **窗口拖动时画面暂时变为非毛玻璃**：这是窗口移动期间主动暂停亚克力和 `D3DImage` 提交，释放 UI 线程与 DWM 合成压力；松开鼠标后会恢复。
- **GPU 画布初始化失败**：在设置中确认“允许软件画布回退”，应用会自动切换到 WPF 后端；远程桌面、旧显卡驱动或禁用 D3D9Ex 共享时优先使用回退模式。
- **画布平移后内容短暂刷新**：视口重绘使用 `DispatcherPriority.Render` 合并连续滚轮/平移事件，避免每个鼠标消息重复提交完整文档。
- **退出前保存提示仍显示“正在保存…”**：正常关闭路径会取消防抖任务，并同步写入最新白板和索引文件。
